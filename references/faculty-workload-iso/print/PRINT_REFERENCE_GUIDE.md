# Faculty Workload Print Layout References (`INS F22`)

Save your physical scanner outputs, signed PDF loading sheets, and printing references in this folder.

### 🖨️ Printing Standards Checklist
- [ ] **Paper Size**: US Letter (`8.5 in × 11 in`), Orientation set to **Portrait**.
- [ ] **Margins**: Top/Bottom `0.25in - 0.35in`, Left/Right `0.35in - 0.45in`.
- [ ] **Strict 1-Page Height**: The entire document (Header + Faculty Profile + Assignments Table + Timetable Grid + 4 Signatures) must compress into **exactly 1 page**.
- [ ] **Dynamic Density Scaling**: The app automatically applies `.fw-density-normal`, `.fw-density-compact`, `.fw-density-dense`, or `.fw-density-ultra` based on row count to guarantee 1-page fit.
- [ ] **Signatures Section**: All 4 signature blocks (Concurred, Verified, Recommending Approval, Approved) fit on page 1.
