# Faculty Workload Image Output References (`INS F22`)

Save reference `.png` images, screenshots, and visual mockups in this folder.

- **Format**: PNG (lossless)
- **Render Engine**: `html2canvas` via `ExportOptions.jsx`
- **Render Canvas Width**: `900px` to `1100px` fixed snapshot envelope
- **Render Scale**: `3` (producing crisp 300+ DPI equivalent print output)
- **Aspect Ratio**: Portrait (~0.77 aspect ratio matching 8.5" × 11")
