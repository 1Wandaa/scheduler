# Class Schedule Print Layout References (`INS-CLS-08`)

Save your physical scanner outputs, PDF sample prints, and printing references in this folder.

### 🖨️ Printing Standards Checklist
- [ ] **Paper Size**: US Letter (`8.5 in × 11 in`), Orientation set to **Landscape**.
- [ ] **Margins**: Top/Bottom `0.25in`, Left/Right `0.35in`.
- [ ] **Page Limit**: Must strictly fit on **1 single page** without spilling to page 2.
- [ ] **Headers/Footers**: Browser URL and date footers disabled (`margin: 0` in `@page`).
- [ ] **Background Graphics**: Enabled in print preview (`-webkit-print-color-adjust: exact`).
- [ ] **Lunch Break Row**: Stretches across all days at `11:30 - 12:30` with `L U N C H   B R E A K` text centered.
- [ ] **Signatures**: Both Prepared by and Approved by blocks appear neatly at the bottom inside the page.
