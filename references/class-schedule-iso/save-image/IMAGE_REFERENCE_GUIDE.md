# Class Schedule Image Output References (`INS-CLS-08`)

Save reference `.png` images, screenshots, and visual mockups in this folder.

### 🖼️ Image Capture Standards
- **Format**: PNG (lossless)
- **Render Engine**: `html2canvas` via `ExportOptions.jsx`
- **Render Canvas Width**: `1100px` fixed snapshot envelope
- **Render Scale**: `3` (producing 3300px width high-resolution raster, equivalent to 300+ DPI print resolution)
- **Aspect Ratio**: Landscape (~1.29 to 1.35 aspect ratio matching 11" × 8.5")
