# Room Utilization Image Output References

Save reference `.png` images, screenshots, and visual mockups in this folder.

### 🖼️ Image Capture Standards
- **Format**: PNG (lossless)
- **Render Engine**: `html2canvas` via `ExportOptions.jsx`
- **Render Canvas Width**: `1100px` fixed snapshot envelope with padding
- **Render Scale**: `3` (producing 3300px width high-resolution raster, 300+ DPI equivalent)
- **Color Fidelity**: Yellow room name (`#ffff00`), Cyan timetable cells (`#00b0f0`), Gold header bar (`#f2a900`).

### 📥 Suggested File Names:
- `Room_Utilization_CL1_Reference_Snapshot.png`
- `Room_Utilization_Sample_HighRes.png`
