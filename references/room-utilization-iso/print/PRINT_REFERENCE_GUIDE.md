# Room Utilization Print Layout References

Save your physical scanner outputs, signed room utilization sheets, and printing references in this folder.

### 🖨️ Printing Standards Checklist
- [ ] **Paper Size**: US Letter (`8.5 in × 11 in`), Orientation set to **Portrait**.
- [ ] **Margins**: Top/Bottom `0.2in`, Left/Right `0.25in`.
- [ ] **Exact 1-Page Height**: The complete layout (Header + Titles + Yellow Room Name + Subjects Table + Timetable Grid + 3 Signatures) must compress into **exactly 1 page**.
- [ ] **Exact Colors**: Yellow `#ffff00` Room Badge and Cyan `#00b0f0` booked cells must be enabled (`-webkit-print-color-adjust: exact`).
- [ ] **Timetable Grid Rows**: Minimum row height `19px` ensuring all hours from 7:00 AM to 6:00 PM fit comfortably.

- `Room_Utilization_CL1_Signed.pdf`
- `Room_Utilization_Print_Proof.pdf`
